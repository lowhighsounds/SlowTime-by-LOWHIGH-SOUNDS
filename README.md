# SlowTime — by LowHigh Sounds

A tempo-synced pitch / loop / reverse effect (VST3) for Windows and macOS.

SlowTime combines three grid-locked blocks:

- **PITCH** — continuous phase-vocoder pitch shift (Smooth / Transient / Punchy).
- **LOOP** — beat-synced chop / vari-speed (1.5× / 2× / 4×) locked to the host grid.
- **REVERSE** — grid-synced reverse with patterns (Always / Ping-Pong / Every 2 / Every 4 / Random).

Plus a per-band filter, tempo-synced fade in/out, and a play-to-pause capture you can
**drag straight into your DAW's playlist**.

## Install

Download the installer for your OS from the
[latest release](https://github.com/lowhighsounds/SlowTime-by-LOWHIGH-SOUNDS/releases),
or grab the build artifacts from the **Actions** tab. Step-by-step (PT-BR) in
[INSTALL.md](INSTALL.md).

- **Windows:** `SlowTime-Installer-Windows.exe`
- **macOS:** `SlowTime-Installer-macOS.pkg`

Format is **VST3**. Works in FL Studio, Ableton Live, Studio One, Cubase, Reaper, Bitwig, etc.
(Pro Tools needs AAX — not provided. Logic Pro needs AU — not built yet.)

> These test builds are **not code-signed**, so Windows SmartScreen / macOS Gatekeeper will
> show a one-time "unknown developer" warning you can click through. See INSTALL.md.

## Build from source

```bash
git clone --recurse-submodules https://github.com/lowhighsounds/SlowTime-by-LOWHIGH-SOUNDS.git
cd SlowTime-by-LOWHIGH-SOUNDS
cmake -S . -B build
cmake --build build --target SlowTime_VST3 --config Release
```

Installers are produced automatically by GitHub Actions (`.github/workflows/build.yml`) for
Windows and macOS. The Windows installer is an Inno Setup script (`installer/SlowTime.iss`);
its branding assets are generated by `installer/make-assets.ps1`.
