# Instalar o SlowTime (guia rápido)

Obrigado por testar o **SlowTime** da **LowHigh Sounds**! É um plugin **VST3**.
Estas versões de teste ainda **não são assinadas**, então o sistema mostra um aviso de
"desenvolvedor desconhecido" — é normal, é só passar por ele (explicado abaixo).

## Windows

1. Baixe o **`SlowTime-Installer-Windows.exe`**.
2. Ao abrir, o Windows pode mostrar uma tela azul do **SmartScreen** ("O Windows protegeu seu PC").
   Clique em **"Mais informações" → "Executar assim mesmo"**.
3. No instalador, siga avançando. Ele já vem apontado para a **pasta padrão de VST3**
   (`C:\Program Files\Common Files\VST3`) — recomendo **manter** essa pasta para o DAW achar
   o plugin. (Se mudar, adicione a pasta escolhida nos caminhos de plugin do seu DAW.)
4. Abra seu DAW e, se preciso, mande **reescanear os plugins VST3**. Procure por **SlowTime**
   (fabricante **LowHigh Sounds**).

## macOS

1. Baixe o **`SlowTime-Installer-macOS.pkg`**.
2. Como não é assinado, o Gatekeeper bloqueia no clique normal. **Clique com o botão direito**
   no `.pkg` → **Abrir** → confirme **Abrir**. (Ou: Ajustes do Sistema → Privacidade e Segurança →
   "Abrir mesmo assim".)
3. Siga o instalador. O plugin vai para `/Library/Audio/Plug-Ins/VST3`.
4. Abra seu DAW e reescaneie os VST3 se necessário.

## Onde funciona

Funciona em qualquer DAW que carregue **VST3**: **FL Studio, Ableton Live, Studio One, Cubase,
Reaper, Bitwig**, etc.

- **Pro Tools:** não suportado (só carrega AAX).
- **Logic Pro:** ainda não (o Logic só carrega AU) — me avise se precisar que eu ative.
